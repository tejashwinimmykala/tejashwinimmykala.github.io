Healthcare data security

consentpath

A multi-site clinical trial enrolment app where authorisation is decided by the data layer through security views keyed on session claims. The reference design is PostgreSQL row-level security; this repo models it with SQLite views. A negative-authorisation test matrix proves the denials.

  • 32-case matrix across 4 roles x 2 sites x 4 participants, asserting denial as well as permit
  • Column-level blinding of arm assignment and consent-gated genomic export
  • 16 tests, plus an append-only access log enforced by triggers
  • TypeScript
  • SQL
  • PostgreSQL
  • Node.js
  • Mermaid

Compliance automation

controlmap

SOC 2 evidence automation that collects exports from GitHub, AWS, identity and HR systems, evaluates YAML controls mapped to the Trust Services Criteria, and builds a hashed evidence package an auditor can verify. It supports an audit and does not replace one.

  • 6 built-in collectors and 22 built-in rules
  • Controls validated against 61 TSC criteria ids and 93 ISO 27001 Annex A controls
  • Evidence package with a checksum manifest, checkable with shasum
  • Python
  • YAML
  • SOC 2
  • ISO 27001
  • GitHub Actions

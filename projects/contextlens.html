contextlens

A VS Code extension that shows who wrote a line, why, and what the PR discussion said, in a hover card. It follows the blame to the pull request, ranks comments by how well they explain the change, and caches them locally.

  • Local SQLite cache makes repeat hovers instant and available offline
  • Rate-limit-aware GitHub client with Retry-After and exponential backoff
  • GitHub token kept in VS Code SecretStorage, never in settings
  • TypeScript
  • VS Code API
  • SQLite
  • GitHub API
  • Vitest

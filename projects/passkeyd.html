Authentication

passkeyd

A Go WebAuthn (passkey) relying-party library and HTTP server with its own CBOR decoder, COSE key parser and a software authenticator for testing. Every rejection carries a stable code naming the check that stopped it.

  • 34 typed verification checks, each with a negative test
  • Replays all 11 WebAuthn Level 3 credential vectors and 82 CBOR examples
  • Threat model mapping 19 threats to mitigations and tests

  • WebAuthn
  • CBOR
  • COSE
  • SQLite

Kubernetes security

admitly

A Kubernetes validating and mutating admission webhook with a CEL policy engine, Audit vs Enforce modes, a built-in security policy library, securityContext defaulting, and cosign-compatible image signature verification.

  • Policies written as CEL, with Audit mode that warns and Enforce mode that denies
  • Built-in policies for privileged containers, required labels, resource limits, registry allow-lists and image digest pinning
  • Mutation sets hardened securityContext defaults only where a workload left a value unset

Status: experimental. It has not been run on a production cluster.
